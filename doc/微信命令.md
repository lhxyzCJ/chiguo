# 微信命令说明(哥哥=操作者)

微信是唯一操作界面(开发时无对话 CLI/TUI)。所有 `/` 开头消息由 bridge 确定性接管,**不经过 LLM**、不污染会话。仅 OWNER_ID 消息可达此路径。

## 命令白名单

| 命令 | 作用 | 示例回复 |
|---|---|---|
| `/new` | 清空当前对话上下文(记忆保留) | "好，清一下。之前的事我都还记着。" |
| `/status` | 上下文/缓存/记忆状态(纯技术) | "会话 6,562 tokens / 1M（0.7%）｜文件 16KB｜上次耗时 38.1s｜缓存命中 7,168｜记忆 193 条" |
| `/记忆` | 记忆库统计 | "记忆库共 195 条。哼，重要的事我都记着呢。" |
| `/记得什么 <词>` | 搜索记忆 | "记得的：· 说好周末吃火锅…" |
| `/help` | 命令列表 | 本表 |

其余任何 `/` 开头消息 → "这是什么咒语啦？我可不会~"，不进 LLM。

## 运维说明

- **`/new` 语义**:只移走当前 chiguo-main 会话文件到 `~/.chiguo/session-backups/<时间戳>-chiguo-main.jsonl`,记忆库/情绪状态/课表全保留;无二次确认(纯手动)
- **恢复备份**:SSH 登录埋埋,`cp ~/.chiguo/session-backups/<文件> ~/.pi/agent/sessions/--root-chiguo-wechat-bridge--/ && touch <新文件>`(touch 更新 mtime,pi 按最近修改续用;备份文件需改回 `_chiguo-main.jsonl` 后缀命名)
- **清理建议**:会话 prompt tokens 达 ~10 万(约 50+ 轮对话,看 `/status` 使用率)时建议 `/new`
- **SSH 侧等效**:`AGENTRUN_NEW_SESSION=1 node scripts/agent-run.mjs --prompt ...` 等效 `/new`(仅默认会话生效)

## 数据源

- `/status` 的耗时/缓存命中来自 `logs/agent-run.log`(agent-run 遥测,一行一轮)
- 记忆统计/搜索走 daemon CLI（`uv run python memory_bridge.py --stats/--search`），数据在 `data/mem0/`（qdrant 嵌入式）
