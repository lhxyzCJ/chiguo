# 微信命令说明（哥哥 = 操作者）

微信是唯一操作界面（开发时无对话 CLI/TUI）。命令分两套体系——**斜杠命令**（ai 会话命令）与
**规则化自然语言命令**（领域命令）——均由 bridge 确定性接管：命中即不进聊天链、不污染 chiguo-main 会话，
仅 OWNER_ID 消息可达。歧义消息放行 agent 自然回复。集成细节见 [doc/AGENT_INTEGRATION.md](AGENT_INTEGRATION.md) §六。

## 命令体系 A：斜杠命令（ai 会话命令，`/` 开头）

| 命令 | 作用 | 示例回复 |
|---|---|---|
| `/new` | 清空当前对话上下文（记忆保留） | "好，清一下。之前的事我都还记着。" |
| `/status` | 上下文/缓存/记忆状态（纯技术） | "会话 6,562 tokens / 1M（0.7%）｜文件 16KB｜上次耗时 38.1s｜缓存命中 7,168｜记忆 193 条" |
| `/记忆` | 记忆库统计 | "记忆库共 195 条。哼，重要的事我都记着呢。" |
| `/记得什么 <词>` | 搜索记忆 | "记得的：· 说好周末吃火锅…" |
| `/help` | 命令列表 | 本表 |

其余任何 `/` 开头消息 → "这是什么咒语啦？我可不会~"，不进 LLM。
斜杠命令由 bridge **纯 node 侧执行**（文件操作 + 记忆 CLI），**不经 agent 也不经 daemon**。

## 命令体系 B：规则化自然语言命令（领域命令）

### B1 纪念日 / 假期（确定性直写 daemon，零 LLM）

| 哥哥说 | 执行 |
|---|---|
| 记住X月X日(是)XX | `chiguo_daemon.py --anniversary "add anniversary MM-DD <名称>"` |
| YYYY年X月X日(是/为/要)XX | `--schedule-change`（写 reminder，显式日期直转写） |
| X月X日要XX（无年份） | `--schedule-change`（写 reminder；今年已过 → 明年，CST） |
| 有哪些纪念日 / 纪念日列表 | `--anniversary list` |
| 放假了 / 放暑假了 | `--break on` |
| 开学了 | `--break off` |

### B2 安排意图（停课/调课/考试周/提醒，经 agent 提取→校验→写）

| 哥哥说 | 动作 |
|---|---|
| 停课 / 不上课 | 取消课次 |
| 调课 / 改到 / 调到 | 调整课次 |
| 加课 / 补课 | 新增课次 |
| 取消 / 撤销 | 撤销安排 |
| 考试周 | 标记考试周 |
| 记住 / 记得 / 提醒 / X月X日… | 写提醒 |

信息不足时 bot 会追问（如"那是调哪一天的课呀？"），你补充回答后自动继续写入。

> ⚠️ **裸「放假了」= 无限期假期**：`--break on` 置 manual_override 无限期（直到手动关闭）。误触发后发
> 「开学了」关闭，或 SSH 执行 `uv run python chiguo_daemon.py --break off`。

## 边界（何时走命令、何时走聊天）

- **斜杠命令**：治理 ai 会话状态（清空/查看/记忆），0 次 LLM；白名单制，未知 `/` 开头一律拒绝。
- **自然语言命令**：治理领域状态（纪念日/假期/课表/提醒）。纪念日/假期零 LLM 直写 daemon；
  安排意图经 agent 独立会话（chiguo-extract/verify）提取→校验→写入，与聊天上下文隔离。
- 歧义消息（问句、`你/您` 开头、超长、语义反转）不拦截，放行 agent 自然回复——**想闲聊就正常说话**。

## 运维说明

- **`/new` 语义**：只移走当前 chiguo-main 会话文件到 `~/.chiguo/session-backups/<时间戳>-chiguo-main.jsonl`，
  记忆库/情绪状态/课表全保留；无二次确认（纯手动）。RPC 常驻模式下 `/new` 后重启 agent 会话
  （下一轮 prompt 重载最新 chiguo-main）。
- **恢复备份**：SSH 登录生产机，`cp ~/.chiguo/session-backups/<文件> ~/.pi/agent/sessions/--root-chiguo-wechat-bridge--/ && touch <新文件>`
  （touch 更新 mtime，agent 按最近修改续用；备份文件需改回 `_chiguo-main.jsonl` 后缀命名）
- **清理建议**：会话 prompt tokens 达 ~10 万（约 50+ 轮对话，看 `/status` 使用率）时建议 `/new`
- **SSH 侧等效**：`AGENTRUN_NEW_SESSION=1 node scripts/agent-run.mjs --prompt ...` 等效 `/new`（仅默认会话生效）

## 数据源

- `/status` 的耗时/缓存命中来自 `logs/agent-run.log`（agent-run 遥测，一行一轮）
- 记忆统计/搜索走 `memory_bridge.py` CLI（mem0 唯一后端：`--stats`/`--search`），数据在 `data/mem0/`（qdrant 嵌入式）
