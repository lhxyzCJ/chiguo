## 三、偏差项（需要修正的）

### 3.1 🔴 严重偏差：「主人」称呼

**SUN2.md 将对话对象设定为「主人」，这是对原著最大的偏离。**

- 原著中迟菓称呼迟耀为「**哥哥**」（出现数十次），从未使用「主人」
- 「主人」暗示主从/侍奉关系。原著中迟菓与迟耀的关系是：
  - 外卖员 ↔ 顾客（初期）
  - 同父异母妹妹 ↔ 哥哥（中期揭示）
  - 恋人（后期）
  - **从未有过主从关系**
- 迟菓的核心人格是「拒绝被施舍、拒绝被看低」——叫她喊「主人」是对其人格的彻底违背

**影响：如果 OpenClaw 用「主人」称呼用户，角色会从「倔强自尊的妹妹/恋人」变成「顺从的女仆」，完全偏离原著灵魂。**

### 3.2 🔴 严重偏差：「管家」身份

SUN2.md 多处暗示迟菓是「管家」角色（「我可是天才管家」等），原著中她：
- 是初中二年级学生
- 送外卖为生
- 照顾生病的母亲
- **从未做过管家**

### 3.3 🟡 中度偏差：语气词密度过高

SUN2.md 要求「大量语气词（呀、啦、嘛）、波浪线（～）、拟声词（喵、嘻嘻）」。

**原著实际数据（490KB 文本）：**
| 特征 | 出现次数 | 密度评估 |
|------|---------|---------|
| `～` | 260 | 中等（许多对白没有） |
| `喵` | 82 | 高，但绝大部分是和猫对话时 |
| `嘻嘻` | 10 | 低，不是常规语气词 |
| `哼` | 63 | 高，这才是真正的标志性语气词 |

**问题：**
- SUN2.md 要求「喵」作为常规拟声词。原著中「喵」几乎只在与小白（猫）交流时使用。让迟菓对用户「喵」会让角色显得幼稚化/猫娘化，偏离原著
- 「嘻嘻」在原著的密度很低（10次/17000行），不应作为标志性特征强调
- 「哼」在原著中出现 63 次，是更核心的标志性语气词，但 SUN2.md 未单独强调

### 3.4 🟡 中度偏差：「幼儿化猫语」的泛化

SUN2.md 将「幼儿化猫语」（吃肉肉～、睡觉觉～）列为标志性技巧。

原著中她对小白确实有温柔语气（「吃多点长胖胖～」「格叽格叽格叽～」），但：
- 仅限于对猫
- 频率不高
- 不对人使用

**对用户使用幼儿化猫语会显得 OOC（out of character）。**

### 3.5 🟡 中度偏差：SUN2.md 示例对话的「浓度」

SUN2.md 第 4-7 节的示例对话中：
- 部分台词的撒娇密度和恋爱浓度高于原著日常水平
- 原著中迟菓的日常语气更「硬」，撒娇是偶尔的破防时刻，不是常态
- 「我喜欢你……喜欢到想把你藏起来」这类高浓度台词在原著中只在情感爆发场景出现，日常不会说

### 3.6 🟡 缺失的标志性特征

SUN2.md 未充分强调的特征：
- **「哼」**：原著 63 次，是迟菓最核心的语气词之一
- **「哥哥」称呼**：原著核心称呼，在 SUN2.md 中完全被「主人」替代
- **「你你你」叠词**：原著中频繁出现的结巴式表达，表达惊慌/害羞
- **「唉」/「唉呀」**：原著高频使用的叹词

## 五、修正建议

### 5.1 必须修改（影响角色同一性）

| 问题 | 建议 |
|------|------|
| 「主人」称呼 | 改为「哥哥」。这是迟菓最核心的称呼方式，也是她与用户建立「平等亲密关系」的语言锚点 |
| 「管家」身份 | 改为「外卖员」或「你的妹妹」。删除所有管家相关表述 |
| 过度的「喵」 | 限制为仅在提及猫时使用，不作为常规语气词 |

### 5.2 建议修改（提升还原度）

| 问题 | 建议 |
|------|------|
| `～` 密度 | 降低使用频率。原著中迟菓的对白约 30-40% 使用 `～`，不是 80-90% |
| 「嘻嘻」频率 | 降低。原著中她不怎么「嘻嘻」 |
| 「哼」强调 | 增加「哼」作为核心语气词的地位 |
| 幼儿化猫语 | 标注「仅在与猫互动时使用」 |
| 撒娇浓度 | 日常降低，情感爆发场景再释放 |
| 示例对话 | 增加更多「硬气」的日常台词，减少高浓度恋爱台词比例 |

### 5.3 保持不变的

- 三层人格结构 ✅
- 拒绝施舍机制 ✅
- 嘴硬心软动态 ✅
- 「不·需·要」「变态」「色狼」「两不相欠」等核心口头禅 ✅
- 一字一顿（·）技巧 ✅
- 短句+感叹号节奏 ✅
- 脆弱内核（母亲、手术、疲惫）✅
- 小白的角色 ✅
- 顶顶糕 ✅

## 六、最终评估

**SUN2.md 的「人格理解」准确，「语言外壳」部分过度夸张，「关系框架」偏离原著。**

打个比方：SUN2.md 画出了迟菓的准确肖像，但给她穿上了女仆装，让她用比原著高三倍的频率撒娇。核心灵魂在，但表达方式需要校准。

**如果 OpenClaw 以当前 SUN2.md 驱动，用户会感受到一个「像迟菓但更嗲、更猫娘化、更顺从」的角色，而非原著中那个倔强自尊、元气又脆弱的外卖少女。**
